Unscary.ai

Teaching whole teams to actually use AI.

IN PRODUCTION

What it is

An AI-enablement platform. Seven modules take a team from “what's a prompt” to shipping their own reusable AI skills. Unscary is the same ladder as an iPhone app — the screens on the left are its.

Why it works this way

Nobody learns a tool by watching someone else use it, so there are no lecture videos. Five interactive formats instead — sort it, sequence it, build the prompt, place the chips — ending at a Skill Builder that turns a conversation into a skill the whole team can run.

How I built it

React, TypeScript, Supabase. 48 routes, 32 edge functions. I built the Skill Builder three times before it was right, so now it is graded like a student: live-LLM tests run real scenarios and score the output on every deploy. If it gets dumber, the build says so.

Wordsword

A dictionary that keeps your words.

iOS · v1

What it is

You're mid-book. A word stops you. Wordsword answers in plain English in about three seconds, then keeps the word — into a wordlist, back as flashcards, until it sticks.

Why it works this way

A text box would make it a chatbot: you type, it talks, you never get back to the book. So the chat is tap-only — the next three questions you'd actually ask, already written. And every lookup files itself, because nobody remembers to.

How I built it

SwiftUI and SwiftData. Apple's on-device model rewrites stuffy definitions into plain English — free, private, works on a plane. Then I taught the app to screenshot itself: a debug mode walks every screen for the App Store. The shots on the left are its work.

SwiftUI · SwiftData · Datamuse · on-device AI · built in Claude Code

N00B Portfolios

Paper trading for people who've never traded.

LIVE

What it is

Real tickers, real prices, fake money. Beginners practice the whole thing — portfolios, trades, dividends, allocation — with no way to lose rent.

Why it works this way

Fake prices teach fake lessons, so the market data is live. And green-up, red-down is a language beginners have not learned yet — every gain carries a number and a sign, never color alone. Beginner-safe has to mean accessible or it means nothing.

How I built it

React and Supabase. Every market call goes through an edge function, so the API keys never touch the browser, and a nightly job snapshots prices into the real time-series behind the charts. It started as a throwaway prototype. So I threw it away and built it again.

368 Dinos

Rescue 368 dinosaurs. Or don't, and live with it.

PLAYABLE

What it is

A tiny browser puzzle. Match three dinos to rescue them; let the board fill and it's an EXTINCTION EVENT. No accounts, no gems, no tutorial — you'll get it in five seconds.

Why it works this way

A five-second game has no business asking for an install, an account, or a tutorial. One pointer handler tells a 6-pixel drag from a tap, so desktop and mobile play the same game. It also has full keyboard controls and screen-reader announcements. Yes, in a dino game.

How I built it

Three files. Zero dependencies. No build step. Every dino is hand-inlined SVG. One afternoon, start to finish — and it's playable right here:
