Skills for designing with, and building for, conversational AI.

Skills

I made these skills to work with conversational AI and build as a product designer. Use any of these in Claude Code.

npx skills add Schubaru/skills

/don-star

An AI design canvas where designers and engineers build together, right in your GitHub repo.

Install, in your terminal

npx skills add Schubaru/skills --skill don-star
Or as a plugin, inside Claude Code
/plugin install don-star --marketplace Schubaru/skills

Paste in Claude Code

/don-star set up the board for [your project]
