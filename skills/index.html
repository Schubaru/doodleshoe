Skills

A skill is a folder of instructions Claude reads before it starts. These are the eight I reach for every day. Take any of them.

npx skills add Schubaru/skills

Picks from all eight. Or grab one below. Source on GitHub.

don-star

A review board that lives inside the app it reviews.

Figma frames go stale the day the code ships. Every frame on this board is the real page, and every comment a reviewer pins is a ticket an agent can pick up and answer in the thread.

Install, in your terminal

npx skills add Schubaru/skills --skill don-star
Or as a plugin, inside Claude Code
/plugin install don-star --marketplace Schubaru/skills

Then, in Claude Code

/don-star set up the board for N00B Portfolios

norm-dog

Don Norman, walking your screens.

Most UX reviews grade how a screen looks. This one asks whether a person can tell what to do and whether it worked, and points at the exact control where they can't.

test-mite

Every route gets a test. Failing tests stay failing.

Routes break quietly. It maps every screen, covers each one with Playwright, and when a test fails it asks whether the app or the test drifted, instead of loosening the test until it passes.
